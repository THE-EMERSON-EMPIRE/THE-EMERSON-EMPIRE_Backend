# Backend Training Exercises

## Exercise 1 — Repository and API Orientation
Document application entry points, routers/controllers, services, data-access layer, configuration boundaries, test locations, API documentation, and local run/test commands.

## Exercise 2 — Validation and Error Handling
Using synthetic requests, improve or demonstrate request validation and consistent error responses. Include tests for valid, invalid, missing, and boundary inputs.

## Exercise 3 — Synthetic Resource Directory
Model a resource record for the future TEE/EPDG resource systems with fields such as official source, URL, country/region, category, eligibility, cost, deadline, language, contact route, last-verified date, reviewer, and status. Use an in-memory/test data source only unless a lead has provided an isolated sandbox database.

## Exercise 4 — Authorization Reasoning
Write tests or a design note demonstrating least privilege, role boundaries, object ownership, and denial behavior. Do not change live role assignments or production access.

## Exercise 5 — Health and Readiness Review
Review existing health/readiness behavior and document the difference between application process health, dependency/database readiness, and authorization failures. Exercise code must not trigger production redeployments.

## Exercise 6 — API Documentation and Handoff
Improve or draft endpoint documentation using synthetic examples. Include purpose, method/path, authorization assumptions, request/response schema, error cases, test evidence, and downstream dependencies.

## Portfolio evidence
Record branch/PR, tests run, screenshots or logs without secrets, privacy/security considerations, collaborator attribution, AI/tool disclosure, reflection, and next step.
